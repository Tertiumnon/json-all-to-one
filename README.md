# JSON-all-to-one

Merge a directory of JSON files into one.

```text
dir/
  file-1.json
  file-2.json
```

## Install

```bash
npm i -g json-all-to-one
```

## Use

```bash
json-all-to-one <dir-with-json-files> <file-to-write>
```

You will receive a file:

```json
{
  "data": [
    { "object1" },
    { "object2" },
    { "etc" }
  ]
}
```

Zero runtime dependencies. Works under both Node.js and [Bun](https://bun.sh).

## Use as a library

```ts
import { concatenate } from 'json-all-to-one';

await concatenate('./dir-with-json-files', './out.json');
```

## Project structure

```text
src/
  lib.ts          library entry (concatenate()), published as dist/lib.js + dist/lib.d.ts
  cli.ts          CLI entry, published as dist/cli.js (bin: json-all-to-one)
test/
  lib.test.ts     bun:test suite
dist/             build output (git-ignored, generated by `bun run build`)
```

The source is TypeScript, run directly by Bun during development. The published package is plain compiled JS with zero runtime dependencies, so it also runs unmodified under plain `node`.

## Development

Requires [Bun](https://bun.sh) `>=1.0`, plus a `tsc` (TypeScript `>=7`) and `biome` binary available globally on your `PATH` — neither is bundled as a project dependency.

```bash
bun install       # installs @types/bun (the only devDependency, ambient types only)
bun test          # run the test suite directly against src/**/*.ts
tsc --noEmit      # typecheck
biome check .     # lint + format check
bun run build     # compile src/ to dist/ (lib.js, lib.d.ts, cli.js) for npm publish
bun run compile   # bundle a standalone native binary to dist/json-all-to-one (no Node/Bun install required to run it)
```
